# Jungle Gaming - Desafio Backend — Processamento Distribuído de Apostas em Go

Este repositório contém a solução para o desafio técnico de backend da Jungle Gaming, focada em construir um sistema de carteiras distribuído, resiliente e consistente.

## Requisitos Pré-requisitos
* **Docker** e **Docker Compose** instalados na máquina.

## Como Executar a Aplicação

O ecossistema inteiro foi orquestrado para subir com um único comando, configurando a base de dados, mensageria e autenticação localmente.

1. Clone o repositório.
2. Na raiz do projeto, execute o comando:
   ```bash
   docker compose up --build
